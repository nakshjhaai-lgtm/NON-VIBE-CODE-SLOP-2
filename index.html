3D editor for the web

Model in 3D. Ship it as code.

PixelForge is a scene editor that runs in a browser tab and writes code you can commit. Build geometry, wire up a material, bind it to scroll, then export React, Vue, Svelte or plain HTML and CSS. No plugin, no build step, no lock-in.

01 / Capabilities

What the editor actually does

Six systems, one scene graph. Each one writes plain code on export, so nothing you build here needs PixelForge to keep running.

01

Real-time viewport

Orbit, pan and frame a scene at 60 fps while shaders compile in the background. The viewport is the document, not a preview of it.

WebGL260 fps budget

02

Node materials

Build a surface from PBR, fresnel and noise nodes. Every node maps to one uniform in the exported shader, so the graph you see is the shader you ship.

24 nodesGLSL output

03

Scroll timeline

Bind any property to page scroll with keyframes and easing curves. The exporter writes a single requestAnimationFrame loop with no library attached.

Keyframes9 easing curves

04

Instancing and LOD

Draw repeated geometry in a single call, then let distance swap in lower detail meshes. Set the thresholds once and the exporter keeps them.

1 draw call3 LOD levels

05

Physics handles

Attach a rigid or soft body solver to a mesh, play the result back, then bake it to keyframes so the export stays deterministic on slow devices.

Rigid bodySoft body

06

Code export

Export to React, Vue, Svelte or plain HTML and CSS. glTF and a standalone WebGL bundle sit one click away for pipelines that start somewhere else.

6 targetsTree shaken

02 / Workflow

Three steps, then you are done

Nothing here needs a project file to be converted at the end. The scene you edit is the source of the code you get.

Step 01

Build the scene

Start from a template or a primitive. Primitives, imported glTF and swept curves all land in the same scene graph.

Step 02

Animate on scroll

Drop keyframes on the timeline, pick an easing curve, and scrub the page to check the motion before you export it.

Step 03

Export the code

Choose a target and copy the output. Here is what a React export looks like:

Scene.tsx 
import { Scene, Mesh } from '@pixelforge/react';

// Generated by PixelForge 2.4.0. Edit freely.
export default function Hero() {
  return (
    <Scene camera={{ fov: 35, position: [0, 1.2, 4] }}>
      <Mesh name="Mesh_01" geometry="geodesic" />
    </Scene>
  );
}
